
# COBOL Loan Management System – Lendwise

A COBOL-based loan management application demonstrating CRUD operations, DB2 integration, embedded SQL, and JCL batch processing.

## Technologies
- COBOL
- IBM DB2
- Embedded SQL
- JCL (Job Control Language)
- z/OS Mainframe Environment

## Key Features
- Loan creation and payment processing
- Loan payment retrieval and updates
- Payment status management
- Loan record deletion
- Database operations using DB2

## Project Structure
The original project source files, JCL scripts, sample data, and database ER diagram are available in the project folder.
